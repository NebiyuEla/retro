# አዲስ ሩጫ — Retro Character Runner

A responsive, dependency-free browser runner starring ገንዘቤ and ስለሺ.

## Run locally

```powershell
npm start
```

Open <http://127.0.0.1:4173>.

## Controls

- `Space`, `↑`, or `W`: jump
- `Shift`, `↓`, or `D`: dash and smash marked wooden crates
- `P` or `Esc`: pause
- Touch devices: use the on-screen Jump and Dash buttons

The opening story is bilingual and skippable. The game begins automatically after the last line.
